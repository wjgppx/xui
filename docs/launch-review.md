# 上线复查与 GitHub 测试站

复查日期：2026-10-30（北京时间）。结论：可以准备和发布隔离的 GitHub Pages 界面演示；目前没有足够证据批准正式运营、真实收款或对外代理服务。演示不提供真实后端，不能代替生产验收。

## 已发现并处理的问题

| 问题 | 处理 |
| --- | --- |
| 后台角色请求等待数据库锁期间，会话已被撤销仍可授予权限 | Web 角色变更在事务内重新检查安全版本、会话、邮箱及 MFA；其他早期后台写入在提交前复查并持锁，拒绝时整批回滚 |
| 空 query/fragment 等 PUBLIC_ORIGIN 被接受，实际浏览器写操作会失败 | 统一严格 Origin 解析，拒绝这些配置并规范化域名、IP 和默认端口 |
| 支付结算把数据库锁超时误报成记录不存在 | 只有真实无记录映射 NotFound；暂时故障保留并交给回调/消费者重试，无部分财务提交 |
| 备份指纹整表 string_agg 存在 PostgreSQL 单值 1GiB 上限 | 同快照、4096 行游标和流式 SHA-256；明确升级 v2 格式，旧 v1 不能未经兼容处理直接恢复 |
| 恢复旧快照可能回退 TOTP 已消费时间步 | 恢复手册推进到当前时间步加一，保留验证器，等待新码，防止恢复窗口重放 |
| 长负载首次投递超时后，验收报告错误显示 pending=0 | 修复所有退出路径的真实账本统计，并记录失败后精确重放与保留证据；恢复成功不抹去压力失败 |

## 验证证据与边界

真实 PostgreSQL 回归使用独立随机 schema，复现等待锁期间的退出、账号安全版本变化、会话到期和 MFA 到期，确认角色、节点令牌、授权、权益、套餐及审计不会从被拒事务泄漏。生产启动验收运行实际控制端程序，检查强制 MFA、Secure/HttpOnly Cookie、开发接口关闭及错误配置启动失败；SMTP 使用不可达的本机地址且不生成邮件，所以不能证明真实邮件投递。

备份 v2 的真实合成库恢复覆盖 16 次迁移、44 表、4098 个订单跨游标批界，核对成功后清理自己创建的源/目标库。没有备份、覆盖或恢复真实业务库。生产代理模板通过本机合成可信 TLS 和临时 Nginx 容器验证，不等于目标域名已部署。

首次 10 分钟、16 worker 应用负载**失败**：25079 个持久样本、25064 个已交批次，15 个客户端投递失败；当时服务端批次、明细与权益金额一致，尚未交付差额为 129960 字节。原报告的 pending=0 是已发现的验收程序错误；旧报告保留，不改写为通过。这不是已证实的服务端丢账，也不是容量验收通过。60 秒同并发原程序复跑通过，说明不能仅归因固定运行时长；需要区分客户端超时、测试主机资源与实际部署性能。

具体本轮测试数量与最终复测结果见[验证记录](verification.md)。依赖扫描中 npm 报告未发现已知漏洞；Go 漏洞数据库访问仍受当前云环境网络策略限制，不能当作扫描通过。

修复后的独立10分钟×16 worker复跑通过：实际600.173秒、47535样本、411843240字节，五层合计一致、pending/差额/意外超时均为0；32次断网投递、16次账本重开、16次丢失确认后的重放全部核对通过。Flush p95桶上界100ms、实际最大628.56ms。新报告为 `.local/acceptance/usage-20261030T042729Z-1881084.json`，原失败报告不改写。本机独立复测不能证明其他并发负载或生产容量达标。

## GitHub 测试站的发布状态

前端演示与自动发布工作流已推送 `main`，提交 `745adfb`。仅在显式演示构建中启用页面内存模拟，一键体验用户/后台、下单、测试支付和权益；真实安全、节点、邮件与资金动作明确不可用。普通生产构建不包含演示数据。

工作流在发布前跑浏览器，发布后检查返回的实际 HTTPS 地址并再次跑浏览器。当前云环境禁止访问 GitHub API 和 `wjgppx.github.io`；网络放行草稿已保存，但工具返回 `requires_publish=true`，尚不能确认实际部署成功或默认网址生效。应以 [Pages Actions](https://github.com/wjgppx/xui/actions/workflows/pages.yml) 的成功部署、Environment URL 和真实访问结果为准。配置及仓库 Pages 权限要求见[测试站手册](github-test-site.md)。

## 正式上线仍需的证据

- 实际生产主机、HTTPS 域名/证书、精确代理来源、专用非超级用户数据库身份；开发 Compose 账号不能直接用于生产。
- 实际 SMTP 认证与收件箱到达；目标商户的授权产品、小额付款/通知/核实及批准范围内的退款验收。
- 真实节点多日运行、容量与额度超用边界、磁盘和队列告警，以及生产规模备份恢复和更新失败回退的实测时间。

以上外部条件尚未核实。可用的操作手册和测试工具已经提供，不能据 GitHub 演示或本地短样本声称正式上线已获通过。
