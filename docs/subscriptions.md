# 订阅与连接凭据

当前提供 VLESS/Trojan TCP+TLS 的通用 URI 列表、Base64 URI 列表、Mihomo 配置与 Xray 客户端配置。配置按公开协议独立生成，没有复用 Air-Universe 的实现。

## 用户操作

登录后进入“我的订阅”，生成链接并保存到客户端。切换格式可复制对应链接或下载完整配置。链接只在生成时显示，离开页面后清除内存中的链接；服务端仅保存令牌 SHA-256 摘要。丢失链接时重新生成，已有客户端需要替换为新链接。

两种轮换具有不同效果：

- 重新生成/撤销订阅链接：旧链接立即无法下载配置，已经导入的代理凭据仍可连接。
- 重置代理凭据：重新生成该用户在所有已授权节点的 VLESS UUID 和 Trojan 密码，不改变其他用户；节点配置进入待应用状态。正常下次协调后旧凭据失效，已有连接被整进程替换中断。失联由最长 60 秒旧授权租约限制；不是实时推送。

客户端在重置代理凭据后需更新订阅。订阅令牌是持有即授权的长期秘密，直到轮换或撤销；不要分享完整链接、记录到公开日志或提交到仓库。部署反向代理时应对订阅路径中的令牌做日志脱敏。订阅 API 使用 no-store 与 no-referrer，不能代替代理的日志配置。

## 发布和筛选

管理员在节点“代理配置”中填写“订阅连接地址/端口”。它们是客户端实际连接的地址，可不同于监听 IP/端口，例如服务器监听 8443、外部入口端口 443。TLS 域名继续用于证书验证。地址留空且端口为 0 时不发布；地址和有效端口必须一起填写。已有配置默认不发布。

订阅按入站模式筛选：手工模式使用显式名单，套餐模式使用该用户购买的节点组快照与当前启用组的成员关系；并要求当前权益已经生效、未撤销、尚未结束且尚有额度；节点身份有效；最近 60 秒内有心跳；当前配置版本已经应用；该绑定有尚未结束的当前权益授权记录。其他用户的凭据、私钥、本地证书路径和监听地址不会导出。

尚未付款、未来周期、过期或耗尽额度、节点未发布、撤销、失联或新配置待应用时，对应节点被排除。客户端刷新时可能短暂看到空列表。已导入配置的撤销仍由节点协调和授权租约负责，删除订阅条目本身不会修改客户端缓存。

## 格式和客户端

| 格式 | 行为 |
| --- | --- |
| uri | 每行一条 vless:// 或 trojan:// URI，包含 TCP、TLS、SNI、ALPN；名称与地址正确转义，支持 IPv6 |
| base64 | 标准 Base64 编码上述 URI 列表；默认格式 |
| clash | JSON 编码的 YAML 1.2 配置，Mihomo 可直接读取；本地 mixed-port=10808、规则 MATCH 到 XUI 选择组 |
| xray | 官方 Xray 客户端 JSON；本地 SOCKS 127.0.0.1:10808，默认第一条代理，其余作为独立 outbound 保留 |

空 URI/Base64 列表为空字符串；空 Mihomo 配置选择 REJECT，空 Xray 配置使用 blackhole。没有 DIRECT 回退。导出的 TLS 始终验证证书；私有 CA 需由用户在客户端的信任配置中安装，不会自动关闭验证。

真实兼容验证使用官方 Xray 26.10.21 和 Mihomo 1.19.15 Linux amd64，两种客户端分别连接 VLESS/Trojan TLS 并验证凭据重置前后的行为。测试仅向临时客户端明确安装临时 CA，Xray 配置额外指定测试 CA；Mihomo 进程使用独立 SSL_CERT_FILE。错误 CA 被拒绝。没有宣称其他版本、UDP、TUN、手机 GUI 或公网性能均已验收。

## 本地验证和版本来源

```bash
python3 scripts/install-xray.py
python3 scripts/install-mihomo.py
bash scripts/test-xray.sh
```

测试脚本读取 XUI_XRAY_BIN 和 XUI_MIHOMO_BIN；默认位于云工作区 shared/tools。CI 使用 runner.temp 独立目录。浏览器流程包含生成、离开页面不回显、轮换、撤销和退出。控制端自动追加迁移 v6；旧节点配置的发布字段缺省为空，Agent 的节点协议无需升级。

Mihomo 使用 GitHub 官方 MetaCubeX/mihomo 的 v1.19.15 发行资产 mihomo-linux-amd64-v1-v1.19.15.gz，固定 SHA-256 为 c52a766af250f789fa8e979f8c6a1c279a526bf2c7dd5d6aaedef74db2f8f366。首次从官方 HTTPS 资产取得并固定哈希，安装器复核后使用；这是复现校验值，没有宣称验证了上游签名。二进制位于工作区工具目录，不纳入本仓库源码。
