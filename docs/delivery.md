# 交付记录

完整方案见 [development-plan.md](development-plan.md)。此增量完成平台基础、交易原型、节点接入，VLESS/Trojan TLS 实际配置应用、持久化流量批次入账、节点组与套餐授权、业务事件投递，以及账号安全、后台角色、邮件投递、支付宝/微信/易支付适配器，以及订单时限、支付自动核实、后台流水、渠道关单、全额退款审批、标准账单导入差异复核、受限原始格式、按需官方下载、每日计划、来源级费用/渠道金额比较与独立资金流水观察账本，不代表完整平台已具备上线条件。

已实现：

- Go 控制端、PostgreSQL 版本化迁移及可重复执行的开发种子套餐。
- 注册、登录、退出、服务端会话、Origin 校验、权限校验和登录限流。
- 用户概览、套餐选择、订单列表、开发支付确认、当前及续费权益。
- 管理员订单汇总、创建套餐及创建操作审计。
- 购买快照、并发支付去重、并发续费串行化、事务发件箱。
- 独立数据库 schema 的集成测试、浏览器操作测试、自动化 CI 和本地启动说明。
- 节点注册、凭据轮换/撤销、心跳和 Agent 常驻进程。
- 后台入站编辑、显式用户授权、当前权益过滤、配置版本冲突检测与实际应用结果。
- Xray TLS 配置校验、独占进程管理、启动探测、失败回退和失联租约停机。
- 真实 Xray VLESS/VMess TCP 动态用户、数据连接和非重置统计实测。
- SQLite 累计游标与不可变待发送批次、控制端批次和序号去重、历史授权校验及原权益周期额度入账。
- 非重置计数采样、正常停止前最终采样，以及计量失败时停止代理。
- 实际 HTTP API 的 OpenAPI 契约和流量计量边界说明。
- 哈希订阅令牌、单独的用户代理凭据轮换、显式节点发布与 URI/Base64/Mihomo/Xray 配置导出。
- 官方 Xray 和 Mihomo 的 VLESS/Trojan TLS 真实客户端兼容与旧凭据拒绝验证。
- 节点组启用/成员管理、套餐授权版本、订单与权益组快照、兼容手工/套餐两种入站模式。
- 权益撤销、时间变化事件、事务发件箱消费、节点投递去重、失败退避/死信和管理员重试。
- 邮箱验证、忘记密码和当前密码校验后的改密；限时单次令牌摘要、替换撤销和会话版本失效。
- 管理员、客服、财务、运维、普通用户五种固定角色，逐接口权限校验、账号列表和角色变更审计。
- PostgreSQL 共享固定窗口限流，直接对端 IP 与邮件地址独立计数，数据库不可用时拒绝放行。
- 账号邮件事务发件箱、强制验证 STARTTLS 的 SMTP 适配器、受限重试与失败状态，以及开发模式的本人测试收件箱。
- 支付宝电脑网站支付 RSA2、微信 Native API v3、常见易支付支付宝/微信 MD5 渠道；显式商户配置、收银台/二维码、通知验签及支付宝/微信可信查询。
- 独立支付意图与渠道固定、交易号/金额核对、并发重复通知去重，以及支付记录/权益/事件原子履约。
- 订单30分钟时限、未发起支付订单的安全关闭、过期订单合法迟到付款履约。
- 支付宝/微信的持久化逐笔核实、租约回收、有界退避与人工重新排队，以及管理员/财务支付流水和追加处理记录。
- 默认关闭的支付宝/微信关单与全额退款、当前密码审批、持久化稳定编号恢复、验签确认后原子撤销原权益，以及后台退款管理。

- 标准CSV账单导入、规范内容去重、收款/退款差异报告、完整日账单反向时间候选、不可变历史版本及追加复核备注；导入和复核不改变金融业务事实。

- 支付宝经典25列部分账单、微信限定SUCCESS/REFUND原始档案导入、来源摘要与完整性标签，以及默认关闭的持久化官方下载任务；没有真实商户验收。

- 管理员/财务授权的每日账单计划，固定北京时间、最近7天有界补排、并发去重、权限/商户变化暂停和未完成自动任务授权撤销。四项计划初始停用，需全局下载开关与计划分别启用。

- 原始来源绑定的精确费用与渠道金额观察、微信相应汇总提示、人工预期CSV比较和不可变报告；不推断净额，不确认银行到账。历史来源需明确重新导入原文件才能首次补充观察。

- 独立规范资金流水导入、固定账户别名/渠道、逐行及期末余额检查、明确双方账户与转账引用的跨日比较，以及重复引用/范围缺失提示；不累加重叠批次，不确认为银行真实到账。

下一交付按依赖顺序进行：

1. 官方资金流水档案及下载接入、目标商户/银行真实文件和账户映射验收、跨批次余额与真实到账核对，真实商户/官方沙箱及更多格式验收。
2. 可信代理策略、权限管理与限流规模验证、邮件服务商端到端投递验收、管理员二次验证。
3. 持续流量下的崩溃/磁盘/网络故障注入、超额测量、跨节点核对及备份恢复。
4. 低中断更新、长期稳定性与升级回退验收。
