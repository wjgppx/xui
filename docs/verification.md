浏览器测试需要控制端、前端和已构建的 `bin/xui-agent`。测试账号使用独立随机标识，节点测试结束时撤销节点并恢复账号为普通用户。完整浏览器流程设定 90 秒总超时，断言仍保留自己的等待上限。截图位于被 Git 忽略的 `web/test-results/`。

前一轮安装脚本已重复执行，没有覆盖现有 `.env.local`。此前已验证 SQLite 依赖的直接下载和 GCC/CGO 构建，Go 模块默认代理下载失败时安装脚本回退至直接下载，继续按 go.sum 校验。Xray 安装器检查固定版本压缩包的 SHA-256 后再解压。数据库测试使用独立 schema，不清理业务表。

当前已验证 SQLite 持久化与真实连接到流量入账、额度撤销的链路。兼容验证覆盖官方 Xray 26.10.21 和 Mihomo 1.19.15 的完整配置。验证仍不包括真实商户支付验收、其他客户端或版本、UDP/TUN、持续负载下的崩溃丢数测量、长期稳定性或公网性能。TLS 验证使用本地临时 CA 和真实 Xray 客户端，出站仅放行临时 echo 测试端口，不等于公网部署验收。节点心跳表示控制通道正常，不能视作代理业务已经就绪。

SQLite 新增依赖为 github.com/mattn/go-sqlite3 v1.14.32，首次 C 源码构建较慢。8 项账本测试包括写入触发器失败回滚、容量满、拆分原子提交、摘要确认、身份绑定和重开恢复。慢校验停机测试允许最多 1 秒进程清理时间，并检测 5 秒校验阻塞是否延长旧租约。

订阅兼容测试固定官方 Mihomo 1.19.15，并校验固定 HTTPS 资产 SHA-256（不是上游签名验证）。私有测试 CA 仅在测试客户端配置中安装；错误 CA 拒绝连接，导出配置不关闭 TLS 验证。详见 subscriptions.md。
