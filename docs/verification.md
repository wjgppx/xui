## 安全与账号

MFA 使用 RFC 6238 TOTP、AES-256-GCM 用户绑定密文、一次性随机恢复码及每会话 15 分钟验证。真实数据库测试覆盖跨会话并发防重放、待确认设置的会话/安全版本绑定、激活原子轮换会话、审计失败回滚、角色变化失效、密码重置保留因子和主机恢复。HTTP 测试覆盖强制绑定、到期、缺钥失败关闭、邮箱、角色、Origin、严格请求体和共享限流。

可信代理默认关闭，仅明确 CIDR 的 TCP 对端能提供有界 X-Forwarded-For。测试覆盖伪造、多级链、IPv4/IPv6、头限制、独立客户端及共享账号计数，且转发头不能改变 Origin/HTTPS。既有角色矩阵及数据库故障拒绝放行继续通过。

SMTP 无发送检查验证连接、STARTTLS、证书和可选 AUTH，在 MAIL/RCPT/DATA 前退出。自动化只连接本机临时 TLS 服务；本轮没有外部发信。真实收件箱及 SPF/DKIM/DMARC 尚待实际服务配置。操作者可明确执行 `xui-mailcheck --send-test --to ...`，SMTP 接受不能当作收件箱到达。见[二次验证](staff-mfa.md)、[可信代理](trusted-proxy.md)和[邮件验收](mail-acceptance.md)。

## 可靠性

负载使用真实回环 TCP 应用数据、私有 SQLite outbox、实际 HTTP 处理器和独立 PostgreSQL schema，多节点扣减同一权益周期。TCP 观察、持久样本、批次 payload、用量明细及权益 used_bytes 五层精确一致；停网、重开和丢失落库响应不会重复扣减。10/30 秒轮 Flush p50/p95 桶上界均为 50ms；1 秒轮实际最大值 45.73ms，p95 桶上界 50ms。它测整次 Flush，不是逐 HTTP SLA；溢出桶使用实际观测最大值作为上界。

真实 Xray 26.10.21 的 VLESS/Trojan TCP+TLS 各在同一连接预热每方向 8192 字节后，传输 96 轮、每方向 1,393,152 字节；两方向内核累计增量与应用字节相等，误差均为 0。此口径不含 TLS/网卡开销，也不证明未采样崩溃窗口为零。

SQLite 子进程分别在提交后和事务未提交时遭 SIGKILL；重开后已提交 WAL 可恢复、未提交游标/批次不可见，差值及序号正确。PostgreSQL 归档和证据共用一致快照，原生恢复到新建随机库，核对行数、约束、索引、触发器及财务/用量/MFA 指纹。本轮未备份或覆盖真实业务库，密钥需独立备份。

私有报告位于 Git 忽略的 `.local/acceptance/usage-20261029T122645Z-1267031.json`、`usage-20261029T122705Z-1267676.json` 和 `usage-20261029T123522Z-1284488.json`，不进入仓库。前两份早于最大值/溢出字段新增，计量结果不变。操作见[负载验收](acceptance.md)、[备份恢复](backup-restore.md)与[流量计量](traffic-metering.md)。

## 发布与升级

真实 VLESS/Trojan 热新增保留已有 TLS 流、PID、实例及累计计数；凭据轮换和用户删除会重启并关闭旧连接。管理 API 假成功、部分成功或慢调用会停止进程，独立租约仍按时终止。默认不启用 HandlerService，启用后依赖本机操作系统与网络隔离。

控制端退出等待在途 HTTP 排空，超时关闭连接后才关闭数据库；真实 HTTP 测试覆盖完整响应与卡住请求的期限。发布工具校验准确发布身份、数据库目标/兼容范围、安全代际、摘要和权限，使用排他锁、原子链接及持久 journal。测试覆盖旧服务仍返回 200、发布失败回退、回退失败保留记录、SIGKILL 恢复、候选损坏和不兼容数据库拒绝旧程序。systemd 模板经过语法校验，未安装或重启真实系统服务。

当前安全代际为 `staff-mfa-v1`，不能自动回退到无 MFA 的 0.15，首次引入需要维护窗口。工具不降级数据库；Agent 二进制重启和其他配置变化仍有中断。见[节点更新](runtime-updates.md)与[发布回退](releases.md)。
