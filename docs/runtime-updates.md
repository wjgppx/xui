# 节点运行时低中断更新

此版本提供显式启用的 **仅新增用户** 热更新。Agent 默认仍通过完整重启应用变化。启用后，VLESS/Trojan TCP + TLS 入站新增用户时可以保留 Xray 进程、已有连接、实例 ID、启动时间和累计流量计数。

```sh
./bin/xui-agent --state /var/lib/xui-agent/identity.json \
  --xray /opt/xray/xray --certificates /etc/xui-agent/certificates \
  --hot-add-users
```

也可以设置 `XUI_HOT_ADD_USERS=true`。该环境变量只接受空值、`true` 或 `false`；命令行标志可以覆盖环境值。观察模式没有 Xray 进程，不能启用此选项。

启用后，本机回环管理端口增加 Xray `HandlerService`。该接口没有应用层身份认证，节点操作系统账号、容器网络命名空间和防火墙属于信任边界。仅在这些边界受控时启用，不要把管理端口发布到宿主机外部。默认模式只启用流量统计服务。

## 更新条件

只有所有既有入站和用户保持一致时，才使用热新增：

- 入站 ID、协议、监听地址、端口、服务器名、证书引用及证书完整内容、私钥内容保持一致。
- 原用户的用户 ID、权益周期 ID、凭证及到期时间保持一致，原用户一个也不能缺少。
- 新配置继续通过 Agent 字段校验、证书校验和 `xray run -test`。

删除用户、修改凭证、续期或缩短用户到期时间、更换权益周期、修改证书及监听设置都执行完整重启。删除或修改用户时，单独调用 Xray 的 RemoveUser 无法保证已建立的连接立即失效，因此这里终止原进程。完整重启和二进制升级会中断当前节点连接；多节点分批升级仍需运营侧安排。

## 失败与租约

Agent 在热新增前后保存流量采样，并逐入站核对管理 API 返回的用户数量。命令退出码为零不足以认定成功。新增命令报错、返回内容无效、前后数量不符、采样失败或操作超时，都会停止进程，保留原配置元数据以便下一次经过完整授权校验后重启。部分新增的不确定状态不会通过删除用户来回退，避免遗留已经建立的连接。

成功更新后才提交新配置并续租。管理调用受调用上下文、五秒操作上限和原租约共同限制；独立租约计时器不等待配置锁或管理命令。网络失联时不延长旧授权。运行时重启、正常回退都取得新实例 ID，热新增保留原实例以继续累计计量。

流量采样与重启之间仍存在尚未采集的窗口。进程或主机突然崩溃时，这个窗口的流量不能从 Xray 的内存统计中恢复；SQLite 只能保证已提交样本和待发送批次的持久性。详见 [流量计量](traffic-metering.md) 与 [可靠性验收](acceptance.md)。

## 验证

普通测试覆盖新增条件、计数响应校验、命令假成功、部分失败、租约到期和成功更新的进程保留。真实内核测试 `TestHotAddPreservesRealTLSStreamsCountersAndRevocation` 分别使用 VLESS、Trojan 的本地 TLS 连接，检查新增用户前后的既有数据流、PID、实例及计量身份，再检查凭证轮换和删除用户会重启并关闭旧连接。

`TestRealTLSMeterPayloadByteAccuracy` 在每个协议的一条既有 TLS 流上预热 8,192 字节并等待统计稳定，再发送 96 轮不同长度的已知应用数据。当前固定 Xray 26.10.21 的本地测试中，每个方向发送并完整回显 1,393,152 字节，VLESS/Trojan 的累计计数增量均为 1,393,152 字节，双向误差均为零。这核对的是连接预热后的应用字节；网络网卡计数还包含 TLS、TCP/IP 等开销，也不能据此声称崩溃前未采样流量零损失。

```sh
bash scripts/go.sh test -race -count=1 ./internal/xraycore
bash scripts/test-xray.sh
```

自动化测试证明这些本地场景的行为；公网长期运行、不同内核版本和实际负载下的中断时间需按 [可靠性验收](acceptance.md) 继续记录。
